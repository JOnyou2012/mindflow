## Design Specificity Verdict

Authored for THIS product at the moments that matter (Stroop calibration in 6 languages, model-honesty surfaces, wizard copy), but the plan page — the product's home — is category-interchangeable: Google Calendar played straight, and the burnout model (the entire differentiator) is nearly invisible there. Four unexplained stat cells and English-only warnings are its only trace.

Deterministic scan: 1 detector finding — `overused-font` (Roboto, index.css:73). Verified as a real declaration but a brief-pinned canon choice (Google Calendar world per DESIGN.md); treated as intentional, not an issue. Nothing else flagged.

## What's Working

1. **QuestionFlow** — one question per screen, auto-advance, IME-safe Enter, inline validation: converts a 6-field form into six one-decision moments.
2. **Stroop results interpretation** — converts α into four bands of concrete study advice; the only place the model speaks the user's language.
3. **Honesty surfaces** — stale-plan banner with inline Regen, unscheduled tasks named, conflicts named. Product principle 4 implemented as UX.

## Priority Issues

1. **[P0] No Operate mode.** Generated sessions are static divs; nothing is clickable, no done-state, no completion persistence. The product thesis (predict burnout, adapt, iterate weekly) dies at generation — users generate once and leave, and no reality feedback ever reaches the model. Fix: clickable session chips → "Mark done" with per-day progress; persist completions; feed last week's completion rate into the next Generate.
2. **[P1] All plan warnings are hardcoded English** (scheduler.js generateWarnings builds English strings; rendered raw in PlanView). 5 of 6 languages see English on the most important screen. Fix: warnings already carry `type` — emit `{type, params}` and template per language in i18n.js.
3. **[P1] The question flow has no exit.** Back disabled at stage 1, footer hidden, no X; stepper escape silently discards, logo escape wipes the whole dataset. Fix: X in the flow header that discards and returns to parent; confirm only when a text stage has content.
4. **[P1] Destructive actions lack guardrails.** Single-task delete = one silent click; GCal "Remove" deletes events from the user's real Google Calendar with no confirmation (gcalUnsyncConfirm translated but never invoked); "Retake" wipes the stored score before a replacement exists. Fix: undo snackbar or confirm for task delete; window.confirm(T.gcalUnsyncConfirm) before deleteSyncedEvents; hold retake in state, persist only on completion.
5. **[P2] The results page never explains the model, and the unscheduled list has no action path.** Stat cells unexplained; no tooltip/help/FAQ anywhere; unscheduled panel names tasks but offers only "try reducing duration". Fix: tooltips on stat cells, a "Why these times?" disclosure, raw sub-scores behind a Details toggle, unscheduled tasks as editable chips + an "increase daily hours" shortcut.

## Persona Red Flags

**Jordan (First-Timer):** first experience is a memorization-demanding test with no "normal score" reference frame; post-generate stats ("Capacity 73%") have no explanation; "SD 87ms" and "/50 /20 /15" are report-card jargon; English warnings in non-EN locales.
**Sam (Accessibility-Dependent):** keyboard tab lands on invisible (opacity-0 hover-revealed) buttons; difficulty stars announce only via `title`; dialogs don't move/trap focus; no aria-live on generation or add-task completion.
**Casey (Distracted Mobile):** both calendar grids force horizontal scroll (min-width 896/826px) and the time gutter scrolls away; stepper labels hidden on mobile; refresh mid-flow loses the in-progress task; Stroop test has no pause.

## Minor Observations

- Footer reads "MindFlow v5" — an internal version string as user-facing copy.
- Stepper "Your plan" vs page title "Your optimized week" — two names for one step.
- i18n carries a dead-string block (welcomeTitle, welcomeStep*, resultsRest w/ emoji, secCalibration).
- Stroop intro never states what a normal score is (skip = 1.0 reference frame missing).
- Empty-week notice on far-future weeks reads as failure rather than "not planned yet".
- No way to re-run generation with unchanged data (Regenerate only via stale banner).
- Quick preset pills ~28px tall — under 44px touch target.
- Settings apply instantly but nothing communicates the changes are live.

## Questions to Consider

1. What if every session chip answered "why here?" on tap instead of the model living in four unexplained stats?
2. What if Generate lived on the plan page itself, and step 4 opened with a "Today" focus mode for returning users?
3. What if the Stroop score were a word ("Sharp / Steady / Variable") with the number behind Details?
4. What if the unscheduled list let you drag a task onto an empty slot and re-solve just that week?
5. What if completions fed "you finished 4/5 planned sessions" into the next generation, closing the loop the thesis depends on?
